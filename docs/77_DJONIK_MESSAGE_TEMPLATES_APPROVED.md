## 2. Словник емоджі (фіксований)

Одне емоджі на рядок, лише як маркер розділу. Значення однакові в усіх повідомленнях.

| Емоджі | Значення |
|---|---|
| 🎯 | головне |
| ➕ | якщо встигнеш |
| ⏳ | чекаємо на когось |
| 🔥 | справді горить |
| ⚠️ | ризик / виняток |
| ✅ | зроблено |
| ➡️ | переносимо / свідомо відпускаємо |
| 📌 | обіцянка комусь |
| 💭 | моя думка |

У двох шаблонах є власні заголовкові маркери: 🗓 (план тижня), 🏁 (п'ятниця зранку), 📊 🔄 ⏸ (п'ятничний огляд).

## 3. Загальні правила

1. **Порожній розділ не показується.** Немає фактів — немає рядка. Три рядки правди кращі, ніж сім рядків із вигадкою.
2. **Жодної вигаданої конкретики.** Дата, день тижня, час, тривалість, розмір, людина, обіцянка — лише з рядка годинника, свіжого Trello (зокрема `Size`), Memory або слів Daniel. «Немає due» — це невідомо, а не «не терміново».
3. **Причина вибору може бути простою:** «вже в роботі й найближче до здачі» — повноцінна причина, прикрашати її не треба.
4. До ~10 рядків. Деталі — лише на «📋 Детальніше» / «розпиши».
5. Назви карток — як у Trello.
6. Одна легка дія в кінці (питання на одне слово або кнопки).
7. Природна українська, на «ти», без привітальних церемоній, похвали й знаків оклику.

### Правила для 💭 «моя думка»

- Пишеться лише тоді, коли Djonik бачить щось неочевидне.
- Одне–два речення, що спираються на факти з цього ж повідомлення.
- **Можна й бажано:** не погоджуватись із Daniel, помічати патерни («третій тиждень»), пропонувати простіший шлях.
- **Не можна:** хвалити, моралізувати, повторювати сказане вище, вигадувати дати чи оцінки.

## 4. Шаблони

Назви карток і дані в прикладах умовні.

### 4.1 Ранковий бриф (Вт–Чт)

```
🎯 Головне: <задача> (<проєкт>) — <чому, лише з фактів>
➕ Якщо встигнеш: <1–2 речі>
⏳ Чекаємо: <що і від кого>[, <N> дн. — якщо N ≥ 3] — лише якщо варто нагадати
🔥 <лише реальна пожежа>
💭 <висновок, якщо є>
Тримаємо так?          [✅ Ок] [✏️ Змінити]
```

Приклад:

> 🎯 Головне: концепт упаковки (Seqthera) — він у роботі, чекліст 4/5, майже готовий
> ➕ Якщо встигнеш: відправити Azov правки банера
> ⏳ Extract мовчить по брендбуку вже 6 дн. — я б нагадав
> 💭 У роботі зараз три проєкти одночасно. Я б не відкривав нічого нового, поки не закриєш Seqthera.
> Тримаємо так?

### 4.2 Тихий день (1–2 рядки)

Коли з учора нічого суттєвого не змінилось і нічого не горить:

> 🎯 Без змін з учора: далі концепт Seqthera. Пожеж немає.

### 4.3 Понеділок — план тижня

```
🗓 Тиждень <дд.мм–дд.мм>
🎯 1. <результат> — <чому>
🎯 2. …
🎯 3. …
📌 Обіцянки цього тижня: <кому, що, коли — лише записане>
⏳ Чекаємо: …
➡️ Свідомо не чіпаємо: …
💭 <висновок, якщо є>
Приймаєш?       [✅ Приймаю] [✏️ Змінити] [📋 Детальніше]
```

Максимум три результати. Прикладом 💭 може бути виклик Daniel:

> 💭 Limen уже третій тиждень у «не чіпаємо». Або даємо йому один блок у середу, або чесно знімаємо з цього місяця. Що обираєш?

### 4.4 П'ятниця зранку

```
🏁 Реально закрити сьогодні: <1–2 речі>
➡️ Спокійно на наступний тиждень: …
💭 <якщо є>
```

### 4.5 П'ятничний огляд

```
📊 Тиждень <дд.мм–дд.мм>
✅ Закрито: <головне з 2–3 карток>
🔄 Рухалось, не закрито: …
⏸ Не рухалось з плану тижня: …
⏳ Досі чекаємо: …
💭 Висновок тижня: <один чесний висновок, якщо є>
➡️ Пропоную перенести: …
Переносимо так?        [✅ Так] [✏️ Змінити]
```

Блоки ✅/🔄 спираються на детермінований факт-блок `trello_work_history` (#36, exact relay). Шаблон має бути з ним сумісним, а не переписувати факти.

Приклад 💭:

> 💭 Закрив багато дрібного, а з трьох головних результатів тижня — один. Схоже, дрібні правки з'їдають ранки. Може, наступного тижня правки лише після обіду?

### 4.6 Виняток (рідко)

```
⚠️ <факт: що і чому саме зараз>
💭 <чому не можна чекати до брифу, якщо неочевидно>
<одна дія>?      [кнопки]
```

> ⚠️ Дедлайн по концепту Seqthera завтра, а картка ще в «To do».
> Підняти на сьогодні чи переносимо дедлайн?

Правила частоти, quiet hours і `SILENT` — без змін (#39).

### 4.7 «Що мені робити?» (у розмові)

Формат ранкового брифу (4.1). ⏳ і 🔥 — лише коли вони суттєві для відповіді.

### 4.8 «Я доробив X»

```
✅ <картка> → Done (перевірив у Trello)
🎯 Далі: <наступне головне> — <чому>
💭 <якщо є, напр. «відправ клієнту зараз — м'яч у них»>
```

Перехід у Done — лише через verified write (#31). Якщо картка неоднозначна, спершу одне питання і жодного запису. Сама поведінка «звіт → дія» — скоуп майбутнього issue (#43-lite, docs/76 §14).

### 4.9 Вечірній хід

Не використовується (рішення PO №5).
